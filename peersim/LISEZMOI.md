# PeerSim 1.0.5 (dépendance tierce)

Ce dossier contient la distribution **non modifiée** du simulateur
[PeerSim 1.0.5](http://peersim.sourceforge.net/) : archives `.jar`, code source (`src/`),
exemples de configuration (`example/`) et notices d'origine (`README`, `CHANGELOG`,
`RELEASE-NOTES`). La documentation Javadoc, volumineuse, n'est pas reprise ici ; elle est
disponible sur le site de PeerSim.

- JEP 2.3.0 / DJEP 1.0.0 : Singular Systems, licence GNU GPL.

Le projet n'a besoin que des trois fichiers `.jar` pour compiler et s'exécuter ; les sources
sont conservées pour respecter les licences.
